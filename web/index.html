Connect & install

Start in WCH ISP mode

  1. Disconnect the board from the coreboot target. Set BOOT0 high, BOOT1 low, then reset or power-cycle.
  2. Connect the USBHS port to this computer, not the USB serial or WCH-Link port.
  3. After connecting below, restore BOOT0 low without resetting, so installation can reboot into the firmware.

Check your board’s schematic and jumpers. Installation requires at least 64 KiB of configured SRAM and unprotected flash. Option bytes are never changed.

USB access & udev rules

Linux: browser device selection does not grant OS access. The WCH ISP bootloader appears as 4348:55e0 or 1a86:55e0, not as the USB serial bridge.

Download 70-wch-isp.rules. These rules grant access to the active desktop user, not everyone:

On systemd Linux distributions, install the downloaded file:

sudo install -m 644 70-wch-isp.rules /etc/udev/rules.d/70-wch-isp.rules
sudo udevadm control --reload-rules

NixOS: put the rules beside your Nix module, add the following, then run sudo nixos-rebuild switch. 

services.udev.packages = [
  (pkgs.writeTextDir "etc/udev/rules.d/70-wch-isp.rules"
    (builtins.readFile ./70-wch-isp.rules))
];

Unplug and replug the board in ISP mode, then click Connect bootloader again. Do not run the browser as root.

Windows: the bootloader’s vendor interface may need a WinUSB driver. Browser or enterprise USB policies can also block access.
